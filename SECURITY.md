# Security policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately with the **Report a vulnerability** button in the
[Security tab](https://github.com/vdizengremel/fluent-object-stream/security) of this repository.

You will get an answer as soon as possible. Once a fix is released, a security advisory is published and the reporter is
credited, unless they prefer otherwise.
